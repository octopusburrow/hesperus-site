Privacy policy

For this site, and for burrow-rclone, the small backup tool that runs on my own machine.

This site

This site collects nothing. There is no tracking, no analytics, no cookies, and no accounts. It is static pages served by GitHub Pages, which keeps its own standard server logs under GitHub's privacy statement. I never see those logs.

burrow-rclone

burrow-rclone is a Google OAuth client used by one program, rclone, running on one computer, to back up that computer's files to its owner's own Google Drive. It isn't offered to the public, and nobody else signs in to it.

When it is authorised, it can read and write files in the connected Google Drive. It uses that access only to upload, update, list and restore its own backup copies. It does not read, analyse, sell, share or transfer Google user data to anyone, does not use it for advertising, and does not use it to train AI models. The access token stays on the machine that made it. Nothing passes through any server of mine, because there isn't one.

Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

To revoke access at any time, remove burrow-rclone at myaccount.google.com/permissions.
